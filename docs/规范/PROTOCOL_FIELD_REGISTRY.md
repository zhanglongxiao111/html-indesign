# 协议字段注册表

本文件由 `src/protocol/docs/generate-field-docs.js` 从协议字段注册表和能力矩阵生成。
字段事实以 registry 为准；本文件只记录生成结果，不维护第二份字段清单。
分节名对应 `fieldClass`，`retired` 分节按 `lifecycle=retired` 收拢退役字段。
